# Glitchlings

Little creatures that live on your Windows desktop. They have moods, memories and opinions of their own, they grow up over real time, and they can step off the desktop into a whole world to explore.

**Download:** [the latest release](https://github.com/blazedsensei/glitchlings-releases/releases/latest) (`Glitchlings-beta.zip`, Windows 10 or 11, 64-bit).
**About the beta:** [blazedsensei.github.io/glitchlings-releases](https://blazedsensei.github.io/glitchlings-releases/)

This repository holds only the downloads. Glitchlings checks here for updates and asks before installing; every update is signed, so a fake one is refused.
